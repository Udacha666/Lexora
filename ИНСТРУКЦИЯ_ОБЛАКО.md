# Lexora Orbit Cloud — один аккаунт на телефоне и компьютере

В этой версии добавлена опциональная синхронизация через Supabase Auth + PostgreSQL.
Сайт не размещён автоматически: сначала нужно создать Supabase-проект и опубликовать файлы.

## 1. Создать базу и авторизацию Supabase

1. Открой https://supabase.com/dashboard → **New project** → создай проект.
2. В **SQL Editor** создай новый запрос, вставь содержимое `supabase-setup.sql` и нажми **Run**.
3. Перейди **Project Settings → API Keys** и найди **Project URL** и **Publishable key** вида `sb_publishable_...`.
4. **Никогда не используй `sb_secret_...`, `service_role` или пароль базы в браузере и GitHub!** Публичный ключ доступен в клиентском коде, но данные защищены правилами RLS.
5. В **Authentication → Providers → Email** включи Email, если он выключен.
6. После публикации сайта в **Authentication → URL Configuration** задай Site URL на публичный адрес сайта, например `https://lexora-orbit.pages.dev`. Если нужно, добавь точный адрес с `/*` в Redirect URLs, чтобы работало подтверждение email.

## 2. Загрузить сайт в Cloudflare Pages (с iPhone)

1. Скачай `Lexora_Orbit_Cloud_Pages.zip` (отдельный ZIP для публикации). Внутри `index.html` лежит в **корне** архива.
2. Открой https://dash.cloudflare.com/ → **Workers & Pages → Create → Pages → Direct Upload** (варианты названий кнопок могут отличаться).
3. Укажи имя проекта `lexora-orbit` и загрузи ZIP через **Drag and drop / Upload assets**, затем **Deploy**.
4. Получи адрес `https://<название>.pages.dev` и открой его на телефоне и ПК.
5. На обоих устройствах открой **Профиль → Единый аккаунт**. Если ключи пока не вписаны в `cloud-config.js`, введи **Project URL** и **Publishable key** в соответствующие поля. Это делается один раз на каждом устройстве. Для настройки сразу на всех устройствах можно вместо этого заполнить `cloud-config.js` в исходном ZIP и заново опубликовать сайт (публичный ключ не является секретом).
6. На телефоне создай аккаунт Email + Password. Подтверди email, если Supabase отправил письмо. На ПК войди **с тем же email и паролем**. Данные подтянутся автоматически.

### Что синхронизируется

- Выученные слова / выражения и повторы.
- Текущий урок, выполненные задания по дням, XP и серия дней.
- Уровень, имя, дневная цель.
- Названия и параметры ИИ-моделей **без секретных ключей**.

API-ключи ИИ не хранятся в Supabase и задаются отдельно на каждом устройстве. Сайт также хранит локальную копию прогресса на случай потери связи. При одновременной работе на двух устройствах возможны конфликты в таких показателях, как XP и текущий шаг урока; желательно не редактировать один урок одновременно на двух устройствах.

## 3. Свой домен (необязательно)

Cloudflare Pages позволяет добавить домен: **Workers & Pages → нужный проект → Custom domains → Set up a custom domain**. Без собственного домена работает бесплатный адрес `*.pages.dev`.

## 4. ИИ-центр

Статический хостинг Cloudflare Pages **не выполняет Node.js-сервер `server/server.mjs`**. Чтобы реальная проверка грамматики и чат работали, нужен отдельный защищённый HTTPS API-сервер, подключенный к `/api/ai` через маршрутизацию/прокси. Без него обычное изучение слов и базовая проверка работают, но обращения к ИИ будут выдавать ошибку. Секретные AI API-ключи нельзя размещать в статических файлах или отправлять в репозиторий.

## 5. Безопасность

- Таблица `lexora_progress` защищена RLS: пользователь читает и меняет только строку со своим `auth.uid()`.
- В `cloud-config.js` допустим только публичный **Publishable** ключ.
- Не показывай пароли, токены и `sb_secret_*` в скриншотах.
- Supabase может просить подтверждение email — это зависит от настроек проекта.
- Если нужен публичный сервис для множества пользователей, понадобятся также защита от злоупотреблений и тестирование безопасности.
